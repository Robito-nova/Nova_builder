# Desktop UI Prototype

The Python/Tk interface is in `nova_builder/ui.py`. It contains project creation/opening, a project explorer, basic text editing and saving, build/package buttons, build output and problem tabs, and a command runner. Long build and terminal work runs in background threads so the UI event loop remains responsive.

## Limits

- Tkinter must be installed with the selected Python distribution (`python3-tk` on Debian; `tk` on Arch).
- The editor is a basic text widget; syntax highlighting, LSP, debugging, project settings, and preview are not implemented.
- Terminal commands use argument splitting and `shell=False`; shell pipelines, shell operators, and interactive sessions are unsupported.
- The UI has not yet been visually or accessibly validated on 1366x768, Windows, or the reference laptop.

## Start

Run `python -m nova_builder ui` or use the `nova ui` entry point after installing the project. Build execution is delegated to the Python build system; the UI does not itself implement language toolchains.
