# NOVA Builder Debian Package

Current preview package: [`Nova-Builder_0.1.0_amd64.deb`](Nova-Builder_0.1.0_amd64.deb)

Install on Debian x86_64 with:

```bash
sudo apt install ./Nova-Builder_0.1.0_amd64.deb
```

Launch NOVA Builder from the desktop application menu or run `nova-builder` in a terminal. The Debian package installs the desktop entry, SVG icon, Python/Tk/jsonschema dependencies, and application files. Verify the download with `sha256sum -c SHA256SUMS`.
